## Інтеграційні перевірки

Перший передчасний прогін під час незавершеного merge не зараховано. Після злиття 22 файли дали 124 passed, 6 failed та 4 errors: старий тест шукав підтвердження всередині картки замість portal-dialog, jsdom dialog API був read-only для guard fixtures, а mock списку джерел повертав StoredObject. ## Розгортання та суміжні роботи

Готується [точний helper розгортання](../../scripts/deploy_admin_review.py): 14 jobs успішного CI того самого SHA; immutable git archive та образи; приватні резервні копії; current env/mounts/ports; primary і priority worker одним orchestrator image. Незалежний R1 знайшов переривання rollback на першій Docker-помилці й відсутній захист від state/network drift під час build; пакет повернений автору. Розгортання до усунення цих дефектів не виконується.

Суміжні новини й оголошення працюють у спільному стеку; координація дозволена користувачем у чаті новин. Перед freeze підхоплюється їхній accepted main, після цього — один повний CI. Їхні сервісні зміни та чинні налаштування не перезаписуються. Actual live browser сценарії, backup receipt, deployed SHA та main SHA будуть додані тільки після виконання.
