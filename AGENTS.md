# Jane — інструкції для агентів

## Де правда
- [TECHNICAL_SPECIFICATION.md](TECHNICAL_SPECIFICATION.md) (ТЗ) — основа. Якщо щось розходиться з ТЗ, пріоритет має ТЗ.
- [plan.md](plan.md) — пакети робіт (WP), власність шляхів (§5), правила (§3), DoD (§4).
- [recomendations.md](recomendations.md) — інструменти для агентів.
- Статус WP: [docs/delivery/status.md](docs/delivery/status.md) (веде координатор). Звіти: `docs/delivery/WP-NN.md`.
- Контракти: `contracts/` (після WP-00). Конвенції API — скіл `jane-contracts`.

## Як працювати над WP
Використовуй скіл `jane-wp`. Коротко: гілка `wp/NN-<назва>`, файл `.jane-wp` з номером WP у корені checkout,
лише свої шляхи з `.Codex/wp-paths.json`, DoD, звіт із реальним виводом команд.

## Команди
Довідник — [DEVELOPMENT.md](DEVELOPMENT.md). just: `uv tool install rust-just` або `uvx --from rust-just just …`.
- `just check` — lint + types + unit + contract (те саме, що CI); `just test <сервіс> [аргументи pytest]`.
- `just up` / `just down -v` — dev-стек з унікальним compose-проєктом і портами; `just env` — адреси й паролі.
- `just new-service <ім'я>` — сервіс із `templates/service/`; спільне — `libs/jane-kit` (не дублюй).
- Тестовий сайт і очікувані URL: [tests/fixtures/testsite/README.md](tests/fixtures/testsite/README.md).

## Мови
Документація й звіти — українською. Код, ідентифікатори, коміти — англійською.

## Заборони
- Не редагувати поза шляхами свого WP (хук блокує Edit/Write; Bash-обходи рев'юер знайде через `check-diff`).
- Не вигадувати поля контракту чи контракти — опиши потребу в розділі «Запити до інших власників» звіту.
- Не послаблювати й не видаляти тести, щоб вони пройшли.
- Не мокати сам компонент, який тестуєш. Моки — лише для сусідів, і лише з контрактів.
- Не зашивати ліміти в код: паралельність, тайм-аути, розміри, бюджети — з конфігурації з безпечними типовими значеннями.
- Не писати «тести зелені», не показавши їхній вивід.
- Не додавати функціональність понад свій WP.
- Не комітити секрети; якщо зовнішнього доступу немає — «не перевірено на реальному сервісі».
- Не зливати в `main`, не робити force push: це робить лише координатор.
- Не читати таблиці іншого сервісу; автономні компоненти не залежать від оркестратора (ТЗ §4).

## Кросплатформність
Windows і Linux. Шляхи через `pathlib`. Ключові команди — без bash-only скриптів (Python, `just`, `uv`).
Тестові стеки — з унікальним compose-проєктом, портами й томами.

## Перевірка власності
```
python .Codex/hooks/jane_wp.py check-diff main
```
