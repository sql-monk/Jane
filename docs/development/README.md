## Основні правила

- Документація й звіти — українською; код, ідентифікатори й коміти — англійською.
- Ключові команди кросплатформні: `just` передає кожен рецепт у `scripts/dev.py` (лише стандартна бібліотека Python), без bash-скриптів. Шляхи в коді — через `pathlib`.
- Спільна логіка сервісів — у [jane-kit](../components/jane-kit/README.md), не дублюється. API — лише з [контрактів](../components/contracts/README.md).
- Ліміти (паралельність, тайм-аути, розміри, бюджети) не зашиваються в код: модель `Limits` із безпечними типовими значеннями.
- Тести не послаблюють і не видаляють, щоб вони пройшли; сам компонент не мокають — моки лише для сусідів і лише з контрактів.
- Секрети не потрапляють у Git: локальні ключі — у `.jane/` (поза Git), перевірка — gitleaks.

Загальний індекс довідників — [docs/reference](../reference/README.md).
