# ADR-0001. Базовий технологічний стек

- **Статус:** прийнято, діє.
- **Звірено з кодом:** ревізія `48389a3`, 2026-10-11.

## Контекст і проблема

Jane складається з кількох автономних сервісів, адміністративного вебінтерфейсу й спільних контрактів (ТЗ §3–4). Сервіси мають мати однакову обв'язку (конфігурація, помилки, журнали, автентифікація), версіоновані API й тести, працювати на Windows і Linux і запускатися локально без хмарної інфраструктури. Екстрактори пишуться на Python (ТЗ §7), тому мова сервісів впливає на повторне використання коду пакетів і SDK.

## Варіанти

1. **Python для всіх сервісів, HTTP/JSON API, PostgreSQL як черга Orchestrator.**
2. Python для обробників, Go або Rust для колекторів — швидший мережевий шар, але два стеки, два набори бібліотек і контрактних тестів.
3. gRPC між сервісами — суворі типи, але складніший виклик зі стороннього застосунку й адмінки; ТЗ вимагає простого автономного використання.
4. Брокер повідомлень (RabbitMQ, Kafka, NATS) для черги етапів — ще одна обов'язкова інфраструктура для кожного розгортання.

## Рішення

Обрано варіант 1.

| Шар | Технологія |
|---|---|
| Сервіси | Python 3.12, FastAPI, Pydantic v2, pydantic-settings, uvicorn, httpx |
| Збірка й залежності | uv workspace (`pyproject.toml`, `uv.lock`): `libs/*`, `services/*`, адаптери Storage, `contracts/python` |
| Спільна бібліотека | `libs/jane-kit`: фабрика застосунку, конфігурація й ліміти, помилки, ідемпотентність, job, автентифікація, health, метрики |
| Контракти | OpenAPI 3.1 і JSON Schema 2020-12 у `contracts/`, шлях `/v1` |
| Стан Orchestrator і черга | PostgreSQL (у dev-стеку `postgres:18`), psycopg 3; черга — `SELECT … FOR UPDATE SKIP LOCKED` |
| Адмінка | TypeScript, React 19, Vite 8, pnpm; клієнт — `openapi-typescript`, `openapi-fetch` |
| Локальне середовище | Docker Compose (`infra/compose.yaml`), Caddy як reverse proxy, MinIO і SeaweedFS як S3-сумісні сховища |
| Команди | `just` поверх `scripts/dev.py` (лише stdlib Python) — однаково на Windows і Linux |
| Тести | pytest, Playwright (адмінка, рендер сторінок Web Collector) |

Тривалі операції — асинхронні job (`202` + `job_id`), решта — синхронні HTTP-виклики ([ADR-0008](0008-api-and-delivery-semantics.md)).

## Наслідки

- Один стек для сервісів, SDK і пакетів екстракторів; спільний код живе в `jane-kit` і не дублюється.
- Без брокера: Orchestrator масштабується кількома екземплярами на одній базі PostgreSQL ([масштабування](../operations/scaling.md)), але черга обмежена можливостями однієї бази.
- Колектори на Python поступаються Go/Rust у пропускній здатності; темп обходу однаково обмежують ліміти джерела.
- Генератор клієнтів `jane-codegen` (`libs/jane-kit/src/jane_kit/codegen.py`) є, але згенерованих моделей у сервісах немає: сервіси використовують власні моделі й перевіряють запити за JSON Schema контрактів.
- Образ MinIO від upstream більше не публікується; dev-стек використовує сторонню збірку `pgsty/minio`, закріплену дайджестом ([infra/README.md](../../infra/README.md#сервіси-стеку)).
