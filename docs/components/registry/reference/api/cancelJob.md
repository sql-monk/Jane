# POST /v1/jobs/{job_id}/cancel

> Згенеровано `scripts/docs_reference.py` з [registry.v1.yaml](../../../../../contracts/openapi/registry.v1.yaml#L783). Не редагуйте вручну.

**Запит на скасування job (ідемпотентний)**

| Властивість | Значення |
|---|---|
| operationId | `cancelJob` |
| Метод і шлях | `POST /v1/jobs/{job_id}/cancel` |
| Scope | `registry:write` |
| Ідемпотентність | не потрібна: cancellation is idempotent by nature |
| Теги | jobs |

202 — скасування прийнято, job переходить у `cancelling`, далі в `cancelled`. 200 — job уже в термінальному стані; повертається як є, без змін. Повторний виклик безпечний, тому Idempotency-Key не потрібен.

## Параметри

| Назва | Де | Тип | Обов'язковий | Опис |
|---|---|---|---|---|
| `job_id` | path | `string` | так |  |

## Тіло запиту

Тип вмісту `application/json`, схема `JobCancelRequest`; обов'язкове: ні.

| Поле | Тип | Обов'язкове | Опис |
|---|---|---|---|
| `reason` | `string` | ні | макс. довжина `1000` |

Приклад `reason`:

```json
{
  "reason": "wrong scope"
}
```

## Відповіді

| Код | Опис | Схема |
|---|---|---|
| `200` | Job уже завершено; стан не змінено. | `job` |
| `202` | Скасування прийнято. | `job` |
| `401` | Немає або недійсний токен (`unauthenticated`). | `problem` |
| `404` | Ресурс не знайдено (`not_found`). | `problem` |

## Примітки

- Помилки повертаються як `application/problem+json` ([модель помилок](../../../../../contracts/docs/errors.md)): `401`, `404`.
- Операція асинхронна: `202` повертає job; стан, прогрес і результат — через `GET /v1/jobs/{job_id}`.
