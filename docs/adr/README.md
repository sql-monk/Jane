# Архітектурні рішення

Архітектурні рішення (ADR) Jane, які діють у поточному коді. Кожне рішення описує контекст і проблему, розглянуті варіанти, вибір і наслідки, а також розбіжності з ТЗ або контрактною документацією, якщо вони є. Рішення 0001–0010 звірено з кодом, контрактами й конфігурацією на ревізії `48389a3` (2026-10-11), рішення 0011 — на ревізії `118707e` (2026-10-12), рішення 0012 — 2026-10-19, зміни поверх ревізії `f8105d34`.

## Відомі розбіжності

- **ТЗ §13.2** описує технологію зберігання пакетів як відкрите питання; реалізація відповідає на нього [ADR-0003](0003-package-registry.md).
- **Транзитне сховище** — карта власності даних ([data-ownership.md](../../contracts/docs/data-ownership.md)) згадує бакет `jane-transit`; у коді транзит лише файловий ([ADR-0005](0005-large-materials.md)).
- **Затвердження версій LLM** — Assistant має `registry:approve` і затверджує версії в режимі `auto_after_checks` ([ADR-0010](0010-llm-in-assistant.md)).

## Нове рішення

Нове рішення додається окремим файлом `NNNN-<коротка-назва>.md` з розділами «Контекст і проблема», «Варіанти», «Рішення», «Наслідки» й рядком «Звірено з кодом» (ревізія, дата). Рішення, яке змінює чинне, позначає попереднє як замінене й посилається на нього.
