# Admin: швидкий старт

Запустіть інтерфейс з контрактними моками. Цей режим показує форми, навігацію й відповіді контрактів; він не збирає реальних матеріалів.

## Передумови

Python та uv потрібні мокам, Node.js — із [.node-version](../../../.node-version), pnpm — `11.27.1` із [package.json](../../../web/admin/package.json). Команди виконуйте з кореня checkout на Windows або Linux.

```powershell
uv sync --all-packages
pnpm --dir web/admin install --frozen-lockfile
```

## Запуск

У першому терміналі:

```powershell
pnpm --dir web/admin mocks
```

У другому:

```powershell
pnpm --dir web/admin dev
```

Відкрийте `http://127.0.0.1:4600`. Vite проксіює `/api/<service>/v1/...` у сім контрактних моків на портах `4611–4617`. У типовому `auth.mode=api_key` введіть ключ тестового середовища: його значення зберігається лише в sessionStorage вкладки. Для режиму без входу замініть `auth` у `web/admin/public/config.json` на `{"mode":"none"}` і перезавантажте сторінку.

## Перша дія

Відкрийте «Джерела», «Завдання» та «Запуски», потім «Пакети». Перевірте завантаження списків і перехід у деталі. Мокові записи походять із контрактів; зміни у цьому режимі не доводять роботу сервісів. [Робота з реальними API](integration.md#реальний-proxy) потребує адреси reverse proxy.

## Збірка

```powershell
pnpm --dir web/admin build
pnpm --dir web/admin preview
```

Результат — `web/admin/dist`. Preview також слухає `127.0.0.1:4600` і потребує моків або налаштованої proxy-цілі. Для production використовуйте статичний сервер з fallback до `index.html` і маршрутизацією `/api`; [експлуатація](operations.md).

## Зупинка

Ctrl+C в обох терміналах зупиняє Vite та запущені скриптом моки. Якщо скрипт аварійно завершився, перевірте свої порти перед повторним запуском. Зупинка інтерфейсу не видаляє дані сервісів.
