# Admin

Admin — вебзастосунок React для джерел, завдань, запусків, матеріалів, результатів, пакетів, підключень, LLM, лімітів і аудиту. Інтерфейс викликає публічні API сервісів через reverse proxy й показує довгі операції у панелі job.

## Межі

Застосунок запускається окремо від повної Jane з контрактними моками. Для реальної роботи потрібні API тих сервісів, сторінки яких відкриває користувач. Admin не має власної бази: бізнес-дані зберігають сервіси; браузер тримає кеш запитів, налаштування теми й API-ключ лише в `sessionStorage`. Адреси та режим входу задає публічний `config.json`, який можна змінити без перебудови.

Браузер звертається до API через proxy; бази належать сервісам.
