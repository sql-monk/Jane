# Пакети й екстрактори

У **Пакети** можна переглянути логіку обробника, його схеми, контрольні приклади, версії та форки.

## Перевірити пакет

1. Відкрий `examples.testsite-price-extractor` і версію `1.0.0`.
2. Переглянь маніфест, код, схему параметрів і `product`.
3. Запусти тести пакета. Для кожного випадку перевір expected/actual і diff; успішне прийняття job ще не означає успішні тести.
4. Додай проблемний матеріал як контрольний приклад перед виправленням коду.

## Оновити

У редакторі створи нову версію, збережи походження зміни й повтори тести. Опублікуй версію та активуй її в потрібному етапі завдання. Якщо пакет спільний, перевір його інші прив’язки; для власних змін створи форк.

Опубліковані байти не перезаписуються. Форки не отримують батьківські зміни автоматично; перенесення через upstream-port створює кандидат для перевірки.

## Контроль після активації

Виконай один запуск і перевір у походженні сутностей саме активовані `package_id`, `version` та `digest`. Відкат активує попередню версію для наступних запусків; уже записані дані не видаляються.

Кроки поза Admin і готовий мінімальний пакет — [довідник пакетів](../reference/packages/README.md).
