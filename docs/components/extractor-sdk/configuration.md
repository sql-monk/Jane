# jane-extractor-sdk: конфігурація

SDK не має власних налаштувань і змінних середовища. На виконання коду пакета впливають параметри етапу з маніфесту, тестовий режим, середовище раннера й ліміти Handler Runtime.

## Параметри етапу

`params` — другий аргумент `extract` і `ctx.params`. Їх задає викликач (етап завдання, запит `handler.v1`, тест маніфесту або `--params` CLI).

- Схему параметрів пакет оголошує в `params_schema` маніфесту (JSON Schema 2020-12).
- Перед викликом підставляються типові значення (`default`) властивостей **верхнього рівня**; вкладені `default` не підставляються.
- Handler Runtime перевіряє параметри за схемою до запуску пісочниці: недійсні параметри — HTTP 422 для виклику або випадок тесту з `failure.kind: invalid_params`.
- `run_local` підставляє ті самі типові значення, але **не перевіряє** параметри за схемою.

Приклад зі зразкового пакета — [params.schema.json](../../../libs/extractor-sdk/examples/testsite-product-extractor/schemas/params.schema.json): `default_currency` (типово `UAH`) і `include_url` (типово `true`).

## Тестовий режим

`ctx.test_mode` — `true` для тест-прогонів, CLI `run` (без `--no-test-mode`) і `run_local` (типово). Значення інформаційне: Handler Runtime і так не пише в робочі дані. Код екстрактора не має поводитися інакше в тестовому режимі, інакше тести перевірятимуть не той код, що працює в завданнях.

## Середовище в пісочниці

| Що | Значення |
|---|---|
| інтерпретатор | `python -I` (ізольований режим: без `PYTHON*` змінних і каталогу користувача) |
| `sys.path` | `<пакет>/src`, `<пакет>` і стандартні шляхи образу |
| поточний каталог і `HOME` | `/tmp` — єдине місце, куди можна писати (розмір `sandbox.tmpfs_mb`) |
| `/work` | пакет, `request.json` і вміст входів; лише читання |
| stdout | зарезервовано під протокол: `print` перенаправлено в stderr |
| змінні середовища | `HOME`, `PYTHONDONTWRITEBYTECODE`, `PYTHONUNBUFFERED` і змінні базового образу; секретів немає |
| мережа | вимкнена |

## Ліміти

Ліміти виконання задає Handler Runtime, а не SDK: час (`sandbox.wall_time_ms`), пам'ять (`sandbox.memory_mb`), CPU, кількість процесів, обсяг виводу, розмір `/tmp`. Типові значення, стелі й спосіб змінити їх у запиті — [конфігурація Handler Runtime](../handler-runtime/configuration.md#ліміти).

Обмеження самого раннера, які не налаштовуються:

| Обмеження | Значення |
|---|---|
| `traceback` винятку в результаті | останні 8000 символів |
| повідомлення винятку | перші 4000 символів |
| зафіксованих порушень пісочниці | 50 |

## Параметри локальних функцій

| Функція | Параметри | Типово |
|---|---|---|
| `run_local(package_dir, handler_input=None, *, file=None, media_type=None, url=None, params=None, test_mode=True)` | вхід — `handler_input` (`HandlerInput`) або `file` | `media_type` вгадується з імені файлу |
| `run_package_tests(package_dir, names=None)` | `names` — підмножина тестів маніфесту | усі тести |
| `assert_package_tests_pass(package_dir, names=None)` | як вище; `AssertionError`, якщо тестів немає або є провали | усі тести |
| `material_from_file(path, *, media_type=None, url=None, source_id=None)` | `source_id` — область ключа сутностей | область `local` |

Сигнатури, результати й винятки — [довідник типів](reference/types/README.md).
