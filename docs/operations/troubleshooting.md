# Діагностика

Починай із ID запуску та конкретного коду помилки. Перевір стан потрібного виконавця, його залежність і effective limits; далі повтори найменшу операцію, яка відтворює проблему.

## Стек не запускається

Переконайся, що Docker працює з Linux containers. Переглянь стан контейнерів лише потрібного compose-проєкту:

```powershell
docker ps -a --filter "label=com.docker.compose.project=jane-demo"
```

Для нездорового контейнера переглянь його журнал за ID з цього списку. Не друкуй весь локальний stack-файл: він містить облікові дані. `stack.py env` показує лише адреси.

## Матеріали не рухаються

| Ознака | Перевірка | Наступна дія |
|---|---|---|
| Колектор буферизує й очікує | Споживач читає feed і підтверджує попередній cursor? | Віднови читання; звір queue/inflight limits |
| Завдання не стартує | Статус, розклад, часова зона, overlap | Перевір наступний час, запусти вручну |
| Invocation має `failed` | Failure kind, diagnostics, package digest | Повтори тест на тому самому матеріалі |
| Job прийнято, результату ще немає | `GET /v1/jobs/{job_id}` і залежності виконавця | Чекай із backoff або скасуй job |
| `unrecognized` | Зміст RAW і сигнатура проблеми | Додай sample-тест та виправ пакет |
| `empty` | Матеріал зрозумілий, потрібних сутностей немає | Перевір очікування; це окремий нормальний результат |
| Запис не змінив сутність | Статус delivery та observation ordering | Звір дубль, stale observation і cleared |

## Доступ і ресурси

`401` означає відсутній або неприйнятий Bearer token; `403` — недостатній scope. Для `412` перечитай документ з актуальним ETag. Для вичерпаного бюджету чи rate limit перевір походження effective limits, а не лише число у формі завдання.

Health перевіряється через `/v1/health`, capabilities і configured limits — через `/v1/info`, метрики — через `/metrics`. У журналах шукай `trace_id`, `run_id`, `stage_id`, `material_id` та `delivery_key`.

Після виправлення [verify](../getting-started/README.md#результат) має підтвердити дані. Не оцінюй відновлення лише за здоровим контейнером. Модульна діагностика — [каталог](../components/README.md).
