## Профілі

`deploy/profiles/dev-laptop.json`, `ci.json`, `single-node.json` задають ліміти збору, черг, invocation, sandbox, LLM і передачі даних. Менш загальний рівень перевизначає платформний, hard caps звужують результат. Сервіс застосовує також власні межі.

## Спостереження

Перевіряй health, `/v1/info`, `/metrics`, журнали й кінцевий результат. Відстежуй розмір черги, затримку матеріалу, повтори, проблемні групи, ліміти та споживання LLM. Підвищення паралельності без перевірки вузького місця може збільшити чергу.

Точні параметри, сховища та життєвий цикл — в `configuration.md` і `operations.md` відповідного модуля. Результати процедур відновлення фіксуються в [DOC-08](../delivery/documentation/DOC-08.md).
