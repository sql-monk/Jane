# WP-26 — вирівнювання гріду й описи параметрів

2026-10-11 виправлено перенесення кнопок у двох рядках візуального редактора та додано пояснення параметрів. Зміни розгорнуто в `jane-demo` і перевірено через браузер на чинних пакетах та завданні [visual-chain-20261011](http://127.0.0.1:54347/tasks/visual-chain-20261011).

## Зміни

- Кнопка розгортання залишається поряд із назвою властивості; кнопки видалення й переміщення — поряд зі значенням.
- Грід зберігає три колонки. На вузькому екрані горизонтально прокручується лише таблиця; сторінка не виходить за ширину екрана.
- Між ідентифікатором, кнопкою видалення етапу та вибором пакета є відступи.
- Пояснення відображаються під назвою параметра й доступні через `aria-describedby`. Поля етапу описані за чинними контрактами; `params` — за JSON Schema вибраного пакета й точної версії.
- Підтримано посилання `$ref`, вкладені об’єкти, масиви й власні ключі з крапками чи дужками. Невідомі та неоднозначні поля не отримують вигаданого опису.
- Для наявних полів схеми `jane.storage-files` додано пояснення форматів `original/html/json`, `json/jsonl` та відповідності `prefix` підключення сховища. Опис автора схеми має пріоритет.
- Підказки пакетів завантажуються через наявні Registry API. Помилка завантаження підказок не блокує редагування.

Основні файли: [PropertyGrid.tsx](../../web/admin/src/components/PropertyGrid.tsx), [ChainEditor.tsx](../../web/admin/src/components/ChainEditor.tsx), [useStagePropertyHelp.ts](../../web/admin/src/components/useStagePropertyHelp.ts), [property-help.ts](../../web/admin/src/lib/property-help.ts), [chain-editor.css](../../web/admin/src/chain-editor.css).
