# Storage

Storage — HTTP-сервіс і виконавець пакетів збереження. Він записує оригінали матеріалів, документи результатів, актуальний стан сутностей та історію спостережень через змінний адаптер. Спільний алгоритм злиття застосовує нові поля, зберігає явно очищені поля та розпізнає запізнілі спостереження.

## Межі

Сторонній клієнт викликає `handler.v1` без Orchestrator. Мінімальний запуск потребує встановленого filesystem-адаптера та каталогу з правом запису; Registry потрібний лише для пакета, якого немає локально. Сервіс не читає таблиць Orchestrator або Registry. Підключення, jobs, HTTP-ключі ідемпотентності й недавні результати викликів зберігаються в пам’яті процесу. Довготривалі дані й записи доставки належать адаптеру.

Клієнт звертається до Storage API; адаптер володіє постійними даними.
