# Діаграми Jane

Кожна схема зберігається трьома файлами: редаговане `.drawio`, прозорий `.light.png` та прозорий `.dark.png`. Геометрія й текст обох тем походять з однієї XML-моделі.

| Тема | Де читати пояснення |
|---|---|
| Контекст, компоненти, залежності, дані, API, стани, deployment | [Діаграми платформи](platform/README.md) |
| Внутрішня будова й життєвий цикл окремого модуля | [Каталог модулів](../components/README.md) → internals |
| Пакет і публікація | [Пакети](../reference/packages/README.md) |
| Перший результат | [Швидкий старт](../getting-started/README.md) |
| Налаштування й сценарії | [Посібник користувача](../user-guide/README.md) |

Редагування та відтворення PNG — [інструменти документації](../development/documentation-tools.md#drawio-та-png). [manifest.json](manifest.json) пов’язує хеш джерела з обома експортами, розмірами й доказом прозорості. Зміна XML без повторного експорту спричиняє помилку перевірки.
