# jane-kit

Спільна бібліотека сервісів Jane: конфігурація з успадкуванням лімітів, автентифікація зі scopes, помилки `application/problem+json`, ідемпотентність, асинхронні job, пагінація, health, метрики, журнали, клієнти інших сервісів і генератор `jane-codegen`.

```powershell
just test jane-kit
```
