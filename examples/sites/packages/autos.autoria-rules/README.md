# Обхід каталогу AUTO.RIA

`autos.autoria-rules@1.1.0` знаходить нові оголошення вживаних легкових
автомобілів у каталозі, відсортованому за датою, і переходить до їхніх карток.

## Межі та налаштування

Правила дозволяють HTTPS на `auto.ria.com` у шляхах `/uk/search/` і `/uk/auto_`.
Селектор каталогу `a.product-card[href*='/uk/auto_'][href$='.html']` бере тільки
посилання карток оголошень. `robots.mode=respect`; JSON API, новини й суміжні
домени поза межами обходу.

| Параметр | Значення в пакеті | Як налаштувати |
|---|---|---|
| `rate.requests_per_second_per_host` | 1 запит/с | Ліміти джерела або завдання |
| `rate.min_delay_ms_per_host` | 1000 мс | Ліміти джерела або завдання |
| `rate.burst_per_host` | 1 | Ліміти джерела або завдання |
| `concurrency.max_parallel_fetches_per_host` | 1 | Ліміти джерела або завдання |
| `crawl.max_pages_per_run` | Успадковується | Ліміти завдання обмежують суму сторінок каталогу й карток |
| `crawl.max_depth` | Успадковується | Ліміти завдання обмежують глибину, зокрема пагінацію |
| `crawl.revisit_interval_seconds` | Успадковується | Ліміти завдання для `revisit.mode=interval` |

Сторінки каталогу читаються в кожному зборі. Відомі картки повторно читаються
за `revisit.mode=interval`. Розклад кожні шість годин налаштовує завдання;
пакет правил не створює окремого таймера. Ефективні обмеження звужують жорсткі
стелі платформи й правила сайту.

## Перевірка

У корені checkout з установленими залежностями виконайте:

```powershell
uv run python examples/automarket/packages/autos.autoria-ad-page/tests/verify.py
```

Команда валідує `rules.json` за контрактом, запускає справжній парсер посилань
Web Collector на позитивних і негативних прикладах та перевіряє межі URL.
