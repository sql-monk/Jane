# WP-12 — оновлення робочого простору адмінки

Дата: 2026-10-10. Стан: review. Гілка: `codex/admin-workspace`.
База: `6e348ce` (актуальний локальний main на момент створення ізольованого checkout).
Власність: `web/admin/**`, цей звіт і докази в `.jane/`; маркер `WP-12`.
Інкремент за прямим дорученням користувача: інформативна адмінка, доступні дії та обов'язкова темна тема.

## Що змінено

- Повністю оновлено оформлення всіх екранів: навігація за групами з пошуком, верхня панель,
  пояснення призначення сторінок, таблиці, форми, статуси, JSON, DAG, diff і адаптивне меню.
- Темна / світла / системна тема, збереження лише теми в localStorage, синхронізація вкладок,
  реакція на ОС і робота при забороненому сховищі. CodeMirror перемикає оформлення й підсвічування
  без втрати чернетки та undo; залежності підсвічування вже були транзитивними, тепер оголошені прямо.
- Огляд: джерела, увімкнені завдання, активні запуски, відкриті групи проблем; блок уваги
  з переходами до невдалих запусків і проблем джерела; останній відомий стан виконавців;
  останні запуски та їхні контрактні лічильники етапів; завдання під рукою й швидкі переходи.
- LLM: витрати, запити й токени за рухомий період 24 години / 7 / 30 днів. Нове оновлення
  пересуває обидві межі часу. Помилки не маскуються нулями; «+» і підпис позначають пагінацію,
  лічильники запусків / увімкнених завдань обмежені завантаженою вибіркою.
- Запуск з огляду й таблиці завдань: тестовий режим типово, явний вибір робочого, причина,
  підтвердження, Idempotency-Key, перехід на сторінку виконання. Активний запуск можна
  зупинити зі списку з підтвердженням і причиною; інтерфейс пояснює збереження вже записаних даних.
- Пошук / фільтри завантажених джерел і завдань; швидкі переходи до завдань джерела й історії.
  Серверні фільтри проблем у URL переживають перезавантаження й не стирають один одного.

Контракти й згенеровані клієнти не змінені. Дані читаються лише через наявні API. Існуючі тести не змінені.
Кореневі правила посилаються на відсутню `.Codex`; чинні карта й перевірка лежать у `.claude/`,
використано їх без зміни правил власності. Назва гілки відповідає префіксу `codex/` поточного середовища.

зі збереженням оформлення. Наявний тест збережено; адресний повтор із новими перевірками нижче.

```text
corepack pnpm e2e --grep 'admin workspace|dashboard: executors|runs, progress'
```

Проміжний адресний запуск мав setup-timeout: одночасний build замінив asset-и preview-сервера.
Остаточний запуск виконано послідовно після завершення build. Новий undo-тест спершу робив
кілька typing-транзакцій, тому один undo прибирав лише останній перенос рядка; введення змінено
на одну `insertText`-транзакцію, збережено сувору перевірку видалення всієї вставки через undo.
У фінальному прогоні були короткі `ECONNREFUSED` повідомлення від mock-проксі між контекстами;
усі 17 сценаріїв пройшли, скриншоти містять завантажені дані, а не помилки.

```text
git diff --cached --check
(exit 0)
gitleaks git --pre-commit --staged --redact --no-banner --exit-code 1
INF no leaks found
```

Нові браузерні сценарії перевіряють теми / збереження / системну зміну / недоступне сховище,
мобільне меню й відсутність зовнішнього горизонтального скролу, пагінацію / 503, точні часові межі LLM,
тестовий і робочий запуск / idempotency, зупинку / причину, URL-фільтри, пошук і переходи,
чернетку коду й undo при перемиканні теми. Скриншоти в `.jane/wp12-admin-{dark,light,mobile,editor-dark}.png`.
Вигляд огляду й мобільного екрана перевірено візуально.

## Межі перевірки

Реальний backend / зовнішні LLM / сайти / Telegram у цьому UI-інкременті не запускалися.
Браузерні докази — контрактні приклади, а не поточні дані робочої платформи. Повний серверний
`just check` і live CI не запускалися: змінено лише frontend, виконано його lint / types / unit / build
та адресну браузерну регресію. Розгортання й злиття в main не виконувалися.

## Запити до інших власників

Немає блокуючих. Повні глобальні агрегати й історична статистика запусків потребують окремих
контрактних endpoint-ів; інтерфейс чесно показує доступну вибірку й не вигадує їх.
