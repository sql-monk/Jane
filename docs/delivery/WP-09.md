## Відомі обмеження

- `concurrency.max_parallel_stage_items` — м'яке обмеження: два воркери, що одночасно беруть елементи того самого
  етапу, можуть на мить перевищити його на кількість воркерів. `queue.*` і дедуплікація — точні.
- `timeouts.stage_timeout_ms`, `timeouts.sync_response_max_ms`, `transfer.job_retention_seconds` оркестратор поки
  не застосовує (прибирання старих запусків немає); ліміти передаються виконавцям як є.
- `auth_mode=jwt` не реалізовано (jane-kit не має перевірки JWT); `none` — лише локально, `api_key` — працює.
  При `none` дії в аудиті записуються від `anonymous`.
- Активація/відкат — лише для `handler`-етапів; версії правил колектора змінюються через PUT завдання/джерела.
- Невідомий матеріал визначається лише тоді, коли в завданні є хоча б один етап із `bindings` (інакше всі
  матеріали «відомі»; валідація попереджає `no_bindings`).
- Вхід `select: problems` — `MaterialInput` + `DataInput {data: {problem: {...}}}`; вихід етапу збереження для
  наступних етапів — `DataInput {data: {writes: [...]}}` (контракт форму не описує, див. запити).
- Повторна обробка з `material_ids` фільтрує список об'єктів storage на боці оркестратора.
- Лічильники запуску (`/v1/runs/{id}`) рахуються запитом `GROUP BY` при кожному читанні.

## Неперевірені інтеграції

- Усі сусіди — фейки з контрактів (`services/orchestrator/tests/orch_support.py`): поведінку написано за
  семантикою контрактів (pull з курсором і підтвердженням, обмежений буфер колектора, ідемпотентність
  обробника з `duplicate: true`, 202 + Job, об'єкти storage), кожен запит оркестратора й кожна відповідь фейка
  перевіряються схемами `collector/handler/storage/registry.v1`. `contracts/tools/mock.py` не використано:
  він віддає статичні приклади без курсора, підтверджень і ідемпотентності, тож не дає перевірити kill/дублі.
- **Не перевірено на реальних сервісах** WP-02 (web-collector), WP-06 (handler-runtime), WP-07 (storage),
  WP-05 (registry), WP-10 (llm) — це приймання M1/M2 (WP-13).
- Тести запускались на Windows; сам сервіс перевірено також у Linux-контейнері (health, ліміти), але повний набір
  тестів на Linux не запускався.
