## Перевірені дії

1. Через UI створено джерело й нове завдання. На вкладці «Ланцюжок» додано handler, перейменовано етап на `store-raw`, вибрано пакет та версію; зв’язок `collect → store-raw` створений редактором.
2. У гріді створено вкладений `params.format`, змінено `raw: html → original`, `entities: json → jsonl`. Створено масив об’єктів `bindings[].url_patterns[]` і масив рядків `media_types`; елементи додано, переставлено й видалено.
3. «Перевірити в оркестраторі» повернуло `ok`; завдання створено й повторно збережено. Після перезавантаження значення й порядок елементів збереглися. JSON-режим етапів не використовувався.
4. Через UI створено файлове підключення з відповідним prefix, а в гріді змінено `connections.target` і вкладені URL-шаблони. Запуск розпочато з вкладки «Запуски».
5. На сторінці запуску підтверджено `succeeded`: collect completed=2, store-raw completed=2/success=2, materials=2, unknown_materials=0. У вкладці елементів із фільтром «усі» видно чотири completed items.
6. У матеріалах застосовано фільтри джерела, підключення й часу останнього запуску: рівно два рядки. Обидва відкрито кнопкою «Переглянути»; показані `Phone Alpha` та `Autumn sale starts` як інертний оригінальний HTML. GET content кожного об’єкта — 200, байти й SHA-256 збігаються. Посилання на історію показує останній run.

Правила тестового сайту — окремий мінімальний collector-rules package: schema validation маніфесту й rules пройшла, upload/approval виконані через реальний registry API як передумова сценарію. Це не UI-створення пакета. Збір обмежений двома локальними URL, robots respect, LLM вимкнений на джерелі.

## Виявлене та виправлене

### Збірка робочої адмінки

На початку сценарію root `web/admin/dist/index.html` посилався на старий `index-C49Qe8kp.js` із JSON-редактором; робочий proxy читав цей mutable каталог. Це відрізнялося від раніше перевіреної збірки `index-Bu3ch0A1.js`.

Перевірену статику скопійовано в `C:/repos/Jane/.jane/releases/admin-ada35865a327`; proxy змінено лише через `up -d --no-deps --no-build --wait proxy`. `JANE_ADMIN_DIST_PATH` і фактичний proxy metadata оновлені в наявному stack-state. Порт 54347 та credentials збережені. Docker bind і фактично завантажений bundle підтверджені; тепер звичайна збірка кореневого checkout не замінює працюючу статику. Чужі локальні код/документація не редагувалися.

### Налаштування простору та шаблонів

Перший RAW збережено в stage prefix `visual-live-20261011`, але connection `raw-files` читало кореневий простір. Файл, metadata й hash підтверджені незалежним рев’юером; втрати даних немає. Це [визначена контрактом семантика namespace](../../contracts/docs/storage-adapter.md), тому адаптер не змінювався. Через UI створено окреме `visual-raw-20261011` з `base_path=/var/lib/jane/storage`, `prefix=visual-live-20261011`, і target переключено на нього.

Початковий тестовий glob `*/news/*` не охоплював вкладений `/news/2026/autumn-sale`: `*` відповідає одному сегменту, `**` — кільком. Значення в масиві відредаговано на `**/news/**` та `**/product/**`. Перші два діагностичні запуски зберегли по одному матеріалу; фінальний запуск правильно зберіг обидва. Попередні дані залишені.
