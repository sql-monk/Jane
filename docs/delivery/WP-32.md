## Розгортання та суміжні роботи

[Точний helper розгортання](../../scripts/deploy_admin_review.py) зафіксовано в `23c0103`: 14 jobs успішного CI того самого SHA; immutable git archive та образи; приватні резервні копії; current env/mounts/ports; primary і priority worker одним orchestrator image. Незалежний R1 знайшов переривання rollback на першій Docker-помилці й відсутній захист від state/network drift під час build. R2 accepted: 28 тестів, Ruff/format/mypy exit 0; первісні негативні сценарії повторені незалежно. Rollback продовжує незалежні безпечні кроки, журналює помилки й не запускає старий writer pool до підтвердженої зупинки нового; fingerprint враховує Running, aliases/IPAM і нові контейнери та повторно перевіряється перед першим stop.

```text
pytest: 28 passed in 0.64s
Ruff: All checks passed!
mypy: Success: no issues found in 2 source files
independent R2: accepted; 28 passed; Ruff/format/mypy exit 0
```

Read-only план `jane-demo` після R2 підтвердив два активні writers та 11 активних запусків; живих змін helper не робив. Стратегія recover зберігає збір і durable identity без cancellation, тоді як drain потребує явно заданого часу природного завершення. Остаточне застосування відбудеться лише після повного CI.

Суміжні новини й оголошення працюють у спільному стеку; координація дозволена користувачем у чаті новин. Перед freeze підхоплюється їхній accepted main, після цього — один повний CI. Їхні сервісні зміни та чинні налаштування не перезаписуються. Actual live browser сценарії, backup receipt, deployed SHA та main SHA будуть додані тільки після виконання.
