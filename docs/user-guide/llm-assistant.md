# LLM та Assistant

LLM надає провайдерів, псевдоніми моделей, бюджети та облік споживання. Assistant використовує ці можливості для підключення джерел і поліпшення пакетів.

## Налаштувати LLM

У **LLM** відкрий **Провайдери LLM**, перевір доступні підключення й секретні посилання. У **Псевдоніми моделей** зв’яжи `cheap`, `strong` або власний alias з провайдером і моделлю. У **Бюджети** задай рівень, ідентифікатор, суму, валюту та період; перечитай збережений бюджет. У **Витрати** переглянь фактичне використання.

Провайдер `fake` призначений для детермінованих локальних сценаріїв. Підключення зовнішнього провайдера описане в [LLM](../components/llm/README.md).

## Підключити джерело

У **Асистент** введи **Назва або посилання**, за потреби тип джерела й **Бюджет дослідження**, натисни **Почати підключення**. Job веде до сесії: переглянь її статус, кандидати, класифікацію, запропоновані пакети й тести. Підтверди відповідне джерело та зміни після перевірки.

## Поліпшити екстрактор

У **Проблеми** вибери групу нерозпізнаних матеріалів і запропонуй поліпшення. Переглянь diff і результати старих та нових тестів. Публікація, підтвердження й активація залежать від політики пакета та явної дії користувача; перевір її перед виконанням.

За вичерпаного бюджету зменш обсяг вибірки або зміни бюджет у **LLM**. Повний перелік обмежень — [configuration](../components/assistant/configuration.md).
