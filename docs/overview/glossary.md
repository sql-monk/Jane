# Терміни Jane

Основні назви для інструкцій, контрактів і діаграм Jane.

## Матеріали та результати

| Термін | Значення | Формат |
|---|---|---|
| Джерело | Сайт, канал або інше місце отримання матеріалів | [Source](../../contracts/schemas/source.schema.json) |
| Матеріал | Вміст разом із джерелом, адресою, часом отримання та ревізією | [Material](../../contracts/schemas/material.schema.json) |
| RAW | Вихідний вміст до обробки | Поле `Material.content` |
| Спостереження | Конкретне отримання матеріалу; повторний збір створює нове спостереження | `observation_id`, `fetched_at` |
| Сутність | Структурований об’єкт із природним ключем і полями | [EntityRecord](../../contracts/schemas/entity.schema.json) |
| Поточний стан | Об’єднані значення полів сутності з урахуванням порядку спостережень | `EntityState` |
| ContentRef | Вміст inline або посилання на blob з метаданими перевірки | [ContentRef](../../contracts/schemas/common/content-ref.schema.json) |
| Транзитний blob | Тимчасовий вміст для передавання; має строк життя | `store: transit` |
| Збережений об’єкт | RAW або інший об’єкт у постійному сховищі | `StoredObjectRef` у [HandlerResult](../../contracts/schemas/handler-result.schema.json) |

## Модулі та пакети

| Термін | Значення |
|---|---|
| Колектор | Сервіс, який отримує матеріали та повертає їх через API |
| Обробник | Операція над матеріалами, сутностями або іншими даними |
| Екстрактор | Пакет обробника для витягування структурованих даних |
| Handler Runtime | Сервіс виконання Python-пакетів |
| Адаптер сховища | Реалізація запису й читання для конкретного сховища |
| Пакет | Маніфест, код або декларація виконання, схеми й тестові приклади |
| Версія пакета | Конкретний незмінний артефакт, вибраний для виконання |
| Форк | Незалежний пакет із посиланням на вихідний пакет і версію |
| Підключення | Налаштування зовнішнього сервісу із посиланнями на секрети |

Типи пакета `extractor`, `transform`, `storage`, `llm`, `collector-rules` задані [контрактом](../../contracts/schemas/common/defs.schema.json). Тип сервісу й тип пакета мають різне призначення: наприклад, Runtime виконує пакети, а Registry зберігає їх.

## Виконання

| Термін | Значення |
|---|---|
| Завдання, task | Джерело, етапи, параметри, розклад і політика виконання |
| Запуск, run | Окреме виконання завдання з зафіксованою конфігурацією |
| Етап, stage | Вузол процесу з пакетом, входами, умовами й параметрами |
| DAG | Граф етапів без циклів; визначає порядок і розгалуження |
| Invocation | Окремий виклик обробника зі входами та контекстом |
| Job | Асинхронна операція сервісу з `job_id` і станом |
| Delivery key | Стабільний ключ технічної доставки, який зберігається під час повторних спроб |
| Lease | Право екземпляра тимчасово виконувати одиницю роботи |
| Backpressure | Призупинення читання нових матеріалів, коли черга обробки заповнена |
| Effective limits | Остаточні обмеження після успадкування та застосування верхніх меж |

`Job.status` описує життєвий цикл операції. `HandlerResult.status` описує зміст результату: `success`, `empty`, `unrecognized`, `failed`. Коректна відсутність сутностей `empty` відрізняється від помилки `failed`.
