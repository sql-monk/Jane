# Каталог модулів

Усі модулі Jane на одній сторінці: тип, призначення, автономність і залежності. Повний опис модуля — у його `README.md` за посиланням із таблиці; як модулі поєднуються — [архітектура](../architecture/README.md).

## Типи модулів

- **Колектор** — отримує матеріали з джерела й повертає їх із метаданими за контрактом `collector.v1`. Бізнес-результатів не зберігає.
- **Обробник** — виконує один етап над переданими даними за контрактом `handler.v1`: збереження, витягування, перетворення або виклик LLM. Екстрактор — це пакет обробника, а не сервіс; його код виконує Handler Runtime.
- **Репозиторій** — зберігає версії пакетів обробників і правил колекторів (`registry.v1`).
- **Координація** — поєднує інші модулі: Orchestrator виконує завдання, Assistant за допомогою LLM готує джерела, правила й екстрактори.
- **Інтерфейс** — вебзастосунок оператора над API сервісів.
- **Бібліотека** — Python-пакет, який підключають сервіси або автори екстракторів.
- **Контракти** — машинозчитувані API, схеми й Python Protocol-и, спільні для всіх модулів.

Пояснення до таблиці:

- **Окремо** — чи можна запустити й використати модуль без інших модулів Jane. Orchestrator сам по собі нічого не збирає й не обробляє — він поєднує виконавців. Assistant без своїх обов'язкових сусідів повертає `upstream_unavailable` для функцій, яким вони потрібні. Admin UI без сервісів працює лише з моками API.
- **Каталог стану** колекторів — локальна база SQLite; кілька екземплярів Web Collector узгоджують ліміти хоста через спільний каталог.
- **Транзитне сховище blob** потрібне для передачі великих матеріалів посиланням; без нього колектор віддає вміст лише в тілі відповіді до `transfer.inline_max_bytes`.
- **Цільове сховище** Storage — PostgreSQL, SQL Server, MongoDB, MinIO, S3 або файлова система; файловому адаптеру потрібен лише каталог. Стандартні пакети збереження `jane.storage-*` вбудовано в сервіс, тому Registry для них не потрібен.
- **Handler Runtime** без PostgreSQL тримає стан у пам'яті — лише для одного екземпляра. Пакет екстрактора можна передати архівом у запиті замість Registry.
- **LLM gateway** має вбудований детермінований провайдер `fake`; реальні відповіді дає провайдер Anthropic за налаштованим підключенням.
- **Registry** для локальних дослідів працює без зовнішніх сервісів: `JANE_REGISTRY_DB=memory`, `JANE_REGISTRY_BLOB=filesystem`. Без профілів Handler Runtime він відхиляє версії екстракторів, що посилаються на профіль виконання.
- **Playwright** потрібен Web Collector лише для рендерингу JavaScript (`fetch.render_js`).
