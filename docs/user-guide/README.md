# Посібник користувача

Сценарії роботи оператора в Admin UI: від входу й підключення джерела до перегляду результатів, виправлення проблем і керування версіями обробників. Кожен сценарій має передумови, кроки й очікуваний результат.

## Перед початком

- Admin UI розгорнуто й відкрито в браузері: dev-стек — [Платформа з Admin UI](../getting-started/platform.md); лише інтерфейс на демонстраційних даних — [швидкий старт Admin UI](../components/admin/quickstart.md).
- Для сценаріїв зі справжнім збором Orchestrator має знати виконавців (колектори, Handler Runtime, Storage, LLM gateway), а Registry — профілі Handler Runtime. Як зв'язати сервіси dev-стеку — у [Платформа з Admin UI](../getting-started/platform.md).
- Терміни (джерело, завдання, етап, колектор, обробник, екстрактор, пакет обробника) — [глосарій](../overview/glossary.md).

Назви сторінок, полів і кнопок звірено з кодом `web/admin/src/pages` на ревізії `48389a3`. Сторінки відкривалися на контрактних моках; сценарії цілком на реальному стеку в межах цього посібника не виконувалися — наскрізний перевірений сценарій без інтерфейсу описано в [наскрізному прикладі](../getting-started/end-to-end.md).

Типовий порядок: увійти, підключити джерело (вручну або з асистентом), перевірити й погодити пакети, зібрати завдання з ланцюжком етапів і розкладом, запустити спершу в тестовому режимі, стежити за запуском, переглянути матеріали й результати. Якщо є збої — розібрати групу проблем, вдосконалити екстрактор, активувати нову версію й повторно обробити збережені матеріали.

## Загальні елементи інтерфейсу

- **Бічна панель** має три групи: «Робочий простір», «Дані та якість», «Налаштування». Поле «Знайти розділ…» фільтрує пункти. Кнопка «Асистент» у верхній панелі доступна з будь-якої сторінки.
- **Огляд** (`/`) показує кількість джерел, увімкнених завдань, запусків у роботі й відкритих проблем, блок «Потребує уваги», останні запуски, витрати LLM за 24 години, 7 або 30 днів, стан виконавців і «Швидкі дії». Кнопка «Оновити» перечитує все.
- **Списки** завантажують перші `page_size` записів (типово 50); «Показати ще» довантажує наступну сторінку. Пошук на «Джерелах» і «Завданнях» шукає лише серед завантаженого.
- **Дії з причиною** («Видалити», «Погодити», «Активувати», «Відкотити», «Зупинити» тощо) спершу показують поле «Причина (для аудиту)» і кнопку підтвердження; «Назад» скасовує дію. Для частини дій причина обов'язкова — кнопка підтвердження неактивна, поки поле порожнє.
- **Помилки** показуються блоком «Помилка … Запит не виконано (`<код>`, HTTP <статус>)». Текст помилки сервісу не показується — лише код; пояснення кодів — [модель помилок](../../contracts/docs/errors.md).
- **Довгі операції** (тести, вдосконалення, підключення через асистента) показують панель job зі станом, прогресом і результатом; стан оновлюється сам. «Скасувати job» зупиняє незавершену операцію.
- **Тестовий режим** запуску й повторної обробки не записує результатів у робочі сховища.
- **Секрети** ніде не показуються: замість значень — `••••••` або посилання `env:`, `file:`, `vault:`.
