## Спільні правила для всіх потоків

- **Інтеграційна гілка — `codex/jane-integration`.** Кожен інкремент — окрема гілка `wp/NN<x>-<назва>` від свіжого
  `origin/codex/jane-integration`, окремий worktree, файл `.jane-wp` з номером пакета (власність —
  [`.claude/wp-paths.json`](../../../.claude/wp-paths.json): потік B — `22`, потік C — `23`, потік A — `19`).
  Хук блокує правки поза шляхами пакета; потрібне чуже — у звіт, розділ «Запити до інших власників».
- **Злиття в інтеграцію** робить лише координатор потоку, з checkout без `.jane-wp`:
  `git fetch origin && git pull --ff-only`, потім `git merge --no-ff <гілка>` з повідомленням
  `merge: accept <WP> …` (ці маркери інші потоки шукають у `git log`), `git push`. Якщо push відхилено (інший потік
  злив раніше) — знову `pull --ff-only`, повторити злиття, без force. **`main` і force push — лише людина.**
- **Якість:** незалежний wp-reviewer на кожен інкремент з кодом (≤2 раунди; якщо раунд 2 знайшов дефект —
  виконавець виправляє, координатор сам перевіряє репро рецензента, третього раунду немає); contract-guardian на
  кожну зміну `contracts/`. Тести не послаблювати; моки — лише сусідів і лише з контрактів.
- **Швидкість:** повний `just e2e` і `just check` локально не ганяти — їх робить CI: push гілки `wp/**` запускає
  lint/types/unit/contract/web; повний прогін з e2e — `gh workflow run ci --ref <гілка>`.
  **Кожен новий чи змінений e2e-сценарій — один локальний прогін; повтори лише якщо впав.** Документи без коду —
  без тестів і рецензентів.
- **Docker-хост зайнятий** контейнерами `puluj-g-*` — їх не чіпати. Власні стеки — з унікальним compose-проєктом
  (`just up --project <унікальне>`), після прогону обов'язково `just down -v --project <те саме>`.
- **Рішення людини:** профілі `dev-laptop` і `single-node` виключено з обсягу повністю — не вимірювати й не вести як
  відкриту роботу. Реальні LLM/IdP/AWS/Telegram без наданого доступу — «не перевірено на реальному сервісі».
- **Повідомлення людині** — лише нове (результат, злиття, падіння, потрібне рішення), 1–2 речення, без переказу
  того, що вже відомо.
- Документація й звіти — українською; код, ідентифікатори, коміти — англійською. Коміти з трейлером співавтора
  вашого агента.
