## Мінімум перевірок (вказівка людини)

- **Документальні зміни** — без тестів і без окремого рецензента: потік A перегляне їх у фінальному рев'ю дельти.
  Достатньо перевірити посилання й відсутність суперечностей із кодом.
- **Зміни коду** — лише lint/typecheck змінених файлів і **один** адресний прогін того, що змінено. Без повторних
  прогонів, без `gh workflow run ci` (повний CI один раз робить потік A на фінальній ревізії). Незалежний рецензент —
  лише якщо змінено код сервісу (не тестів і не документації), і один раунд.
