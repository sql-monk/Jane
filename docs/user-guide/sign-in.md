# Вхід

Як увійти в Admin UI ключем API або через постачальника ідентичності, вийти й змінити тему оформлення. Спосіб входу визначає `auth.mode` у `config.json` розгортання ([конфігурація](../components/admin/configuration.md#автентифікація)).

## Вхід ключем API

Передумови:

- адреса адмінки (у dev-стеку — `JANE_STACK_PROXY_URL` з `just env`);
- ключ адміністратора (у dev-стеку — `JANE_STACK_AUTH_ADMIN_API_KEY` з `just env`). Не пересилайте ключ і не вставляйте його в адресний рядок.

Кроки:

1. Відкрийте адресу адмінки. Без входу будь-яка сторінка перенаправляє на сторінку «Jane — адмінка».
2. Вставте ключ у поле «Ключ API». Кнопка «Увійти» активна, коли поле не порожнє.
3. Натисніть «Увійти».

Очікуваний результат: відкривається сторінка, на яку ви переходили (або «Огляд»). Внизу бічної панелі — «Робочий простір» і «API key». Ключ зберігається лише в цій вкладці до її закриття або виходу; нова вкладка чи вікно попросить увійти знову.

## Вхід через постачальника ідентичності

Передумова: розгортання налаштоване на `auth.mode = "oidc"`.

1. На сторінці входу натисніть «Увійти через IdP».
2. Увійдіть на сторінці постачальника.
3. Після повернення адмінка показує «Завершення входу…» і переходить на «Огляд».

Очікуваний результат: внизу бічної панелі — ваш email або ім'я з профілю. Токен оновлюється автоматично. Цей спосіб на ревізії `48389a3` не перевірявся з реальним постачальником.

## Сесія прострочена

Якщо ключ неправильний, відкликаний або токен прострочився, над вмістом сторінки з'являється банер «Сесія недійсна або прострочена (401). Увійти знову». Натисніть «Увійти знову» й увійдіть з актуальним ключем. Дійсний ключ без потрібних прав банера не викликає: такі дії показують помилку з кодом `forbidden`.

## Вихід

Натисніть «Вийти» внизу бічної панелі. Ключ видаляється з вкладки; за входу через постачальника ідентичності адмінка переходить на його сторінку виходу. У режимі без автентифікації (`auth.mode = "none"`) кнопки «Вийти» немає, у панелі — «Локальний режим».

## Тема оформлення

Перемикач «Тема оформлення» є у верхній панелі й на сторінці входу: «Темна», «Світла» або «Системна» (за налаштуванням операційної системи). Вибір запам'ятовується в цьому браузері й застосовується в усіх відкритих вкладках адмінки.
