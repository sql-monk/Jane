# Документація Jane

Jane — модульна платформа, яка збирає матеріали із сайтів і Telegram-каналів, витягує з них структуровані сутності й зберігає результати у вибрані сховища. Ця сторінка — зміст документації й маршрути читання для користувача, розробника й адміністратора.

## Маршрут користувача

Для того, хто налаштовує джерела й завдання та працює з результатами.

1. [Огляд](overview/README.md) і [глосарій](overview/glossary.md) — що робить Jane і як називаються її поняття.
2. [Наскрізний сценарій](getting-started/end-to-end.md) — від джерела до збережених сутностей на тестовому магазині.
3. [Посібник користувача](user-guide/README.md) — джерела, завдання, пакети, результати й помилки в Admin UI.
4. [Виконання завдання](architecture/task-execution.md) — етапи, стани запуску, повтори, повторна обробка.
5. [Обмеження](overview/limitations.md) — що поки не підтримано або не перевірено.

## Маршрут розробника

Для того, хто змінює модулі, пише екстрактори або інтегрує модуль у свій застосунок.

1. [Архітектура](architecture/README.md) і [карта репозиторію](architecture/repository-map.md) — з чого складається платформа й де лежить код.
2. [Розробка](development/README.md) — середовище, команди перевірки, тести.
3. [Каталог модулів](components/README.md) — документація потрібного модуля: самостійний запуск, залежності, налаштування, інтеграція, будова.
4. [Довідники](reference/README.md) — API, типи, [пакети обробників](reference/packages/README.md).
5. [Архітектурні рішення](adr/README.md) — чому зроблено саме так.

## Маршрут адміністратора

Для того, хто розгортає й обслуговує платформу.

1. [Платформа з Admin UI](getting-started/platform.md) — підняти dev-стек.
2. [Розгортання](architecture/deployment.md) — контейнери, способи запуску, профілі лімітів, масштабування.
3. [Безпека](architecture/security.md) — ключі API, секрети, ізоляція коду екстракторів.
4. [Власність даних](architecture/data-ownership.md) — які сховища має кожен модуль.
5. [Експлуатація](operations/README.md) — моніторинг, оновлення, резервування, відновлення; `operations.md` окремих модулів — у [каталозі](components/README.md).
