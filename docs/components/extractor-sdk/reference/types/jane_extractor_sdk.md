# Модуль `jane_extractor_sdk`

> Згенеровано `scripts/docs_reference.py` з [libs/extractor-sdk/src/jane_extractor_sdk/__init__.py](../../../../../libs/extractor-sdk/src/jane_extractor_sdk/__init__.py). Не редагуйте вручну.

SDK for Jane Python extractors.

Write ``extract(material, params, ctx)`` and return one of :func:`success`, :func:`empty`, :func:`unrecognized` (raise an exception to fail). See README.md of this package.
