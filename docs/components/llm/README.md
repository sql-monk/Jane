# LLM

LLM — шлюз до мовних моделей і виконавець пакетів виду `llm`. Він вибирає модель за псевдонімом, відокремлює інструкції від даних джерела, перевіряє структурований результат, резервує бюджет до виклику й обліковує фактичне споживання.

## Межі

`POST /v1/completions` доступний сторонньому застосунку без Orchestrator, Assistant і Registry. Для локального демо достатньо `store=memory` та вбудованого fake-провайдера. Типовий режим `postgres` потребує власної PostgreSQL-схеми; спільний стан дає кільком екземплярам узгоджені бюджети, jobs і ключі ідемпотентності. Registry потрібний для віддаленого пакета, а локальний пакет працює без нього. Реальний зовнішній провайдер у цій перевірці не викликався.
