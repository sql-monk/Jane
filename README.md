# Jane

Jane — платформа, яка збирає матеріали із сайтів і Telegram, перетворює їх на структуровані дані та зберігає в обраних користувачем сховищах. Наприклад, вона може збирати картки товарів, регулярно перевіряти ціни або витягувати події з повідомлень.

Користувач задає джерело, потрібні дані та послідовність обробки. Велика мовна модель (LLM) допомагає створювати й удосконалювати екстрактори — програми, які витягують потрібні поля з матеріалів. Код можна переглядати, редагувати й тестувати через адміністративний інтерфейс.

Платформа складається з автономних сервісів, що взаємодіють через API. Колектор отримує матеріали, обробники виконують задані операції, а оркестратор керує завданнями та розкладами. Кожен компонент можна використовувати окремо у власному застосунку.

Репозиторій обробників містить версіоновані пакети для витягування даних, збереження, звернення до LLM та інших перетворень. Екстрактор — один із типів обробника. Пакети можна тестувати, використовувати в завданнях і незалежно форкувати; зміни батьківського пакета не застосовуються до форку автоматично.

Проєкт названо на честь докторки Джейн Гудолл — на знак поваги до її внеску в спостереження, дослідження та розуміння живого світу. Jane є незалежним проєктом і не має офіційного зв’язку з Jane Goodall Institute; назва не означає його підтримки або схвалення.
