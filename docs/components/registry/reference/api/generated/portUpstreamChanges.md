# portUpstreamChanges

Явно перенести зміни батька у форк новою версією (асинхронно)

Контракт: [contracts/openapi/registry.v1.yaml](../../../../../../contracts/openapi/registry.v1.yaml).

```http
POST /v1/packages/{package_id}/upstream-ports
```

## Опис із контракту

```text
Лише за явною командою користувача (ТЗ §7). Трьохстороннє злиття: база — остання
перенесена версія батька, «їхні» — `parent_version`, «наші» — `base_version` форку.
Успіх — `Job.result` = PackageVersion (draft) з `provenance.upstream_port`. Конфлікти —
job `failed` з кодом `upstream_conflict` і переліком файлів у `error.details.conflicts`.
```

## Доступ

```json
{
  "scope": "registry:write",
  "security": [
    {
      "bearerAuth": []
    }
  ]
}
```
